# SA Associates Asset Structure

- `branding/` — logo, favicon and brand artwork
- `hero/` — homepage hero backgrounds and student cutouts by destination
- `destinations/` — Study Destinations section backgrounds and campus images
- `services/` — service cards and 4-step journey imagery
- `company/` — CEO imagery, company-section backgrounds and registration artwork
- `contact/` — Contact page visual assets
- `reviews/google/` — Google review avatars and review images
- `success/` — student, visitor, spouse/work-permit and supporting success-story imagery
- `team/` — staff portraits, normalized to lowercase kebab-case filenames
- `memberships/` — membership/accreditation logos
- `flags/` — country and region flags
- `ui/` — small decorative UI artwork
- `st.jpg` — intentionally kept at `/assets/st.jpg` because the Student Visa card uses the public URL `https://saavisa.com/assets/st.jpg`.

Filenames are descriptive and use lowercase kebab-case wherever practical.
